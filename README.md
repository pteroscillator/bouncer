# Bouncer

Balls bounce in a box and every hit on the floor, the walls or another ball makes a sound, with controls for gravity, volume and the number of balls. Space starts and stops the sound, R throws new balls. Made for a computer.

Live: https://pteroscillator.github.io/bouncer/

Browsers tested: Safari and Firefox on macOS

Web Audio behaves differently on Safari and iOS. On iOS, the sound plays even with the silent switch on (Safari 16.4 or later).
